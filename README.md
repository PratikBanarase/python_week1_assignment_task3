# Python Mini Challenges

# Project Overview

The Python Mini Challenges are a collection of small programming exercises developed as part of the Python Week 1 Assignment.
These challenges are designed to improve Python problem-solving skills and provide practice with strings, lists, dictionaries, loops, conditions, indexing, slicing, and built-in functions.

# Objective

The objective of these challenges is to strengthen:
- Python fundamentals
- Problem-solving skills
- Logical thinking
- Loops
- Conditional statements
- String manipulation
- List operations
- Dictionary operations
- Input-output handling
- Problem decomposition

# Challenges Included

The assignment requires at least:
- 3 String Problems
- 3 List Problems
- 3 Dictionary Problems

# String Challenges

# 1. Reverse a String

Reverse the given string using Python string slicing.
# Example
Input:
python internship
Output:
pihsnretni nohtyp

# 2. Count Vowels

Count the number of vowels present in a sentence.
# Example
Input:
Python Programming
Output:
Number of vowels: 4

# 3. Check Palindrome

Check whether a string reads the same forward and backward.
# Example
Input:
madam
Output:
Palindrome

# List Challenges

# 1. Find Largest and Smallest Number

Find the largest and smallest values from a list of numbers
# Example:
Input:
[10, 5, 20, 8, 15]
Output:
Largest: 20
Smallest: 5

# 2. Remove Duplicates

Remove duplicate values from a list.
# Example
Input:
[4, 7, 2, 7, 9, 2]
Output:
[4, 7, 2, 9]

# 3. Count Even and Odd Numbers

Count how many numbers in a list are even and how many are odd.
# Example
Input:
[1, 2, 3, 4, 5, 6]
Output:
Even: 3
Odd: 3

# Dictionary Challenges

# 1. Character Frequency

Count how many times each character appears in a string.
# Example
Input:
banana
Output:
{'b': 1, 'a': 3, 'n': 2}

# 2. Find Key With Maximum Value

Find the key associated with the highest value in a dictionary.
# Example
Input:
{
    "Neha": 91,
    "Arjun": 85,
    "Rahul": 88
}
Output:
Top student: Neha

# 3. Calculate Student Marks Average

Calculate the average of values stored in a dictionary.
# Example
Input:
{
    "Math": 90,
    "Python": 95,
    "SQL": 85
}
Output:
Average: 90.0
